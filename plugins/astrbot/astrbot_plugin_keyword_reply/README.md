# 关键词回复

AstrBot 的 Telegram 群关键词自动回复插件。规则由 AstrBot 管理面板编辑，不需要 AI 模型或知识库。

## 安装

在 AstrBot 管理面板的「插件 → 安装插件」上传本插件 ZIP。安装后打开插件详情中的「rules」页面管理规则。也可以将整个插件目录放进 AstrBot 的 `data/plugins/`，再重载插件。

在 BotFather 对机器人执行 `/setprivacy` → `Disable`，否则 Telegram 不会把普通群消息完整发送给机器人。将机器人加入目标群；如果启用「删除触发消息」，还要授予删除消息权限。

## 新建规则

1. 在目标群发送 `/sid` 获取群 ID；填入「Telegram 群 ID」。话题 ID 留空表示整个群。
2. 可填写规则名称以便在列表中辨认；名称不参与匹配。设置关键词和匹配方式：包含、完全相同或正则表达式。消息文字／媒体说明、文件名、贴纸 Emoji 可多选，任意一项命中即触发；至少保留一项。
3. 添加一个或多个文字或媒体回复。媒体可直接上传图片、GIF、MP4、MP3、OGG、WAV 或 PDF，单个不超过 20 MB。
4. 选择随机发送一条或按顺序发送全部；可设置冷却、引用原消息、删除原消息、忽略转发消息、规则优先级。
5. 可以在左侧搜索或按启用状态筛选规则；右侧显示回复预览。支持复制规则、导入和导出 JSON。
6. 点击「保存更改」，在群里发一条普通消息测试。若多条规则同时命中，只执行优先级最高的一条；同优先级按列表顺序执行。

规则和媒体存放在 AstrBot 的 `data/plugin_data/astrbot_plugin_keyword_reply/`。安装更新时请保留该目录。未点击「保存更改」的管理页修改不会生效。快捷键 `⌘S` / `Ctrl+S` 也可保存。

## 从旧插件迁移

插件内部标识已变更，AstrBot 会将它作为新插件安装。先关闭旧版关键词插件，准备旧规则 JSON，再安装本插件，在管理页「导入」并「保存更改」。确认回复正常后再卸载旧版，避免两个插件同时回复。若旧规则含媒体回复，还需把旧数据目录的 `media/` 文件复制到新数据目录的 `media/`，否则媒体规则无法保存。

## 当前范围

只处理 AstrBot 内置 Telegram 适配器收到的群消息。机器人账号发送回复。媒体上传格式由文件扩展名识别；Telegram 不接受文件时，插件会记录发送错误。正则规则仅由管理面板管理员编辑，请避免复杂回溯表达式。

管理页规则保存后仍需在目标群发送消息，检查 Telegram 机器人的实际回复。

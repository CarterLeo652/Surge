## v0.4.1 后台与交互回归

- 扣减覆盖 7 天边界、7 档渐进、整数向上取整、0 和负数边界、当日去重、多线程并发、进程重建、故障回滚和重新签到后停止闲置扣减。
- 核对缩水保持签到时间、连签、PK 战绩和贷款余额，并与并发签到保持账本一致。
- 12 小时签到设置下，后台仍按 UTC 自然日运行。后台支持从已加载的 Telegram 平台发现客户端，重启后无需等待新指令来恢复队列。
- 待提醒累计数按玩家、群、机器人隔离，发送时扣除已告知的快照数量，保留同时新产生的缩水量。
- 清理覆盖默认永久保留、管理员身份与按钮申请人校验、权限变化、缺少删除权限时的原版确认流程、只删除自身回复、触发指令一并清理、PK 与贷款结算后重分类。
- 队列覆盖数据库租约、防重复领取、陈旧任务完成保护、重试、Telegram RetryAfter、消息已被手动删除和到期处理。
- 用真实 AstrBot 持久化回调路由验证清理菜单和后台任务退出。每日缩水在本地 API 模拟下保持静默。
- 验证真实 Telegram SDK 发出的签到累计提醒、发送失败后重启补发、重复签到补发、并发签到只提醒一次，以及其他玩家和命令对待提醒数量的隔离。
- 升级回归验证旧待发通知转换一次并取消旧租约，保留当日标记及已有数据，后续只累计个人待提醒数量。

## v0.4.2 菜单关闭回归

- 主菜单、时间选择页、缺少删除权限的确认页都提供关闭按钮。
- 通过真实 Telegram SDK 和 AstrBot 回调路由验证删除原菜单、检查菜单所有者和管理员权限、取消菜单的待清理任务。

## v0.5.0 指令与回调命名

- 注册命令和 Telegram 菜单均使用 `/dick_` 前缀；`/dick_of_day` 保持原名，不注册旧的无前缀别名。
- 新按钮统一使用 `dick:*` 回调动作。插件重载后本版按钮仍可处理；升级前的 `pinjj:*` 按钮不再注册处理器，需重新发送对应命令。
- 旧插件数据库复制与命令、回调标识无关，保留原有迁移路径。

## v0.6.0 群组启用范围

- 总开关默认开启；白名单留空表示全部群，黑名单优先。群 ID 支持配置中的字符串或数字值。
- 禁用群的命令不发送回复，已有按钮不能完成 PK 等结算；后台不在该群执行缩水，到期清理任务取消。
- 私聊统计只汇总当前启用的群；更改配置不删除群内已有游戏数据。

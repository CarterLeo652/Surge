# DickGrowerBot

适用于 **AstrBot v4.29.4** 的 Telegram 游戏插件，版本 **v0.6.0**。移植原项目的六项功能，核心回复、菜单描述和按钮使用原项目中文文案，签到附加已确认的累计缩水提醒。中文语言文件随插件附带，统计回复省略固定的历史日期提示。

## 安装

1. 已安装旧「拼鸡鸡」插件时，先停用旧插件，避免相同指令被重复处理。
2. 在 AstrBot 插件管理页面上传 `astrbot_plugin_dickgrowerbot-v0.6.0.zip` 并启用 **DickGrowerBot**。源码安装目录为 `AstrBot/data/plugins/astrbot_plugin_dickgrowerbot/`。
3. 配置 AstrBot 的 Telegram 适配器，将机器人加入群聊，再发送 `/dick_grow`。

要求 Python 3.12 或以上，AstrBot 元数据兼容范围为 `>=4.29.4,<5`，本地实际验证版本为 4.29.4。插件声明 PyYAML 依赖，Telegram SDK 由 AstrBot 提供。

接管原机器人 Token 时，先停止原 bot 进程，再启用 AstrBot 接收更新。群消息接收权限及网络配置遵循 AstrBot 的 Telegram 接入说明。命令示例使用 `/`，实际前缀由 AstrBot 配置决定。[官方接入说明](https://docs.astrbot.app/platform/telegram.html)

## 指令

| 指令 | 原版菜单描述 |
| --- | --- |
| `/dick_grow` | 让你的丁丁变大！ |
| `/dick_top` | 获取聊天中最大的丁丁 |
| `/dick_of_day` | 选举今日丁丁 |
| `/dick_pvp` | 斗鸡！ |
| `/dick_loan` | 负数？申请贷款！ |
| `/dick_stats` | 统计 |

`/dick_pvp 5` 发起押注 5 厘米的挑战，其他玩家点击「斗鸡！」应战，结算后更新原消息。排行榜使用「⬅️」「➡️」翻页。贷款使用「我同意！」「不同意」按钮，由申请者确认。

`/dick_stats` 在群内显示本群个人统计，在私聊中显示跨群个人汇总。Telegram 菜单由 AstrBot 适配器导出，受框架命令注册设置和刷新周期影响。

## 自动删除

群管理员发送 `/dick_cleanup`，通过原版按钮菜单分别设置四类消息的保留时间。各级菜单底部增加「✖️ 关闭」，由打开菜单的管理员操作，关闭时结束该菜单的清理排期。

| 类别 | 包含内容 |
| --- | --- |
| 提示与拒绝 | 重复签到、重复每日评选、错误提示、剩余欠款提示 |
| 排行榜 | 排行榜和个人统计 |
| 成长与战绩 | 成功签到、每日评选、PK 结果、贷款结果 |
| 挑战与邀约 | 待应战挑战、贷款确认、清理设置菜单 |

**默认四类均永久保留**。可选择 1、5、15、60、180 分钟，或恢复永久保留。原版「听机器人的」和「全部听机器人的」按钮恢复本插件的永久保留默认值。

清理设置作用于之后发送的消息及后续编辑。翻页和结算后按当前消息类别重新计时，已排期的其他消息按原计划执行。建议先给提示设置 1 分钟、排行榜设置 5 分钟，按需决定成长战报和待处理申请的保留时间。

具备删除消息权限时，会同时安排删除触发指令。权限不足时展示原版确认说明，确认后只清理机器人自己的回复。处理任务时再次核对权限，删除任务保存至数据库，重启后继续执行，短暂失败会重试。长消息按原版阅读速度延长保留时间，最终清理受 Telegram 消息年龄限制约束。

## 闲置自动缩水

- 固定按 UTC 自然日，即北京时间 08:00 进入下一天，与 `refresh_hours` 分别计时。
- 满 7 天未签到后开始扣减，对正长度生效，每次至少扣 1 厘米，最多扣到 0。
- 采用已确认的原项目示例参数，上限为当前长度的 10%，从第一档开始，用 7 档逐步升到上限。
- 例如首次符合条件时，100 厘米扣 2 厘米。后续按剩余长度和闲置天数向上取整计算。
- 重新签到后重新计算闲置时间。缩水只调整长度，签到时间、连签、PK 战绩和贷款欠款按各自机制记录。
- 每群每日在同一个事务中完成长度扣减、累计待提醒数量和当日执行标记，重复运行与重启按当日标记去重。
- 启动或恢复时补跑当前一天。每日后台检查完成后，本人下次发送 `/dick_grow` 时会看到累计缩水提醒。
- 提醒随签到回复发送，例如「太久没签到了，你的鸡鸡累计缩水了 3 厘米。」重复签到提示也能附带此前发送失败的提醒。
- 累计数按机器人、群和玩家分别保存。发送成功后扣除本次已告知的数量，发送失败或重启后继续保留。
- 升级 v0.4.0 时，尚在队列中的旧缩水通知会转换为个人待提醒累计数，已有当日执行标记继续用于防止重复扣减。

## 配置

在 **AstrBot → 插件 → DickGrowerBot → 配置** 设置后重载。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关；关闭后不响应命令和按钮，也不执行后台任务 |
| `enabled_groups` | `[]` | 群白名单；留空表示所有 Telegram 群，填写群 ID 后只在这些群启用 |
| `disabled_groups` | `[]` | 群黑名单；优先于白名单 |
| `refresh_hours` | `24` | 签到刷新间隔，单位为小时，支持小数，最低 1 分钟，最高 8760 小时 |

群 ID 使用 Telegram 群的数字 ID，例如 `-1001234567890`。名单按整个群生效，同一超级群的所有话题共用设置。禁用群不会删除已有游戏数据；禁用期间到期的消息清理任务会取消，重新启用后不会补删。私聊 `/dick_stats` 只统计当前启用的群。

例如 `24` 为每 24 小时，`12` 为每 12 小时，`1` 为每小时，`0.5` 为每半小时。

刷新采用全体共享的固定周期，以 UTC 的 1970-01-01 零点为起点连续划分。默认每天 UTC 00:00，即北京时间 **08:00** 刷新。重启或重载沿用当前周期。修改间隔立即按新周期判断签到资格。

## 游戏规则

- 每个机器人、每个群的长度和战绩独立保存，同一超级群的不同话题共享数据。
- 签到基础变化为 `-5～10` 厘米，正负概率各 50%，基础值不取零。新手保护和连签奖励沿用原规则，连签按 UTC 自然日计算。
- 负数仍可继续签到，并享受原版 1% 负长度补助。PK 发起者须有足够赌注，应战者长度须非负，输家可能变成负数。
- 每群每天 UTC 零点后可评选一次今日丁丁，与签到刷新间隔分别计时。候选人来自最近 7 天签到的玩家，按原规则排除长度靠前的玩家，获选增加 1～5 厘米。
- 负长度玩家可申请贷款，将长度归零。之后从正增长、PK 获胜收益及每日评选奖励中按 10% 偿还，整数舍入沿用原版规则。

## 数据与旧版升级

新数据保存在 `AstrBot/data/plugin_data/astrbot_plugin_dickgrowerbot/dickgrowerbot.sqlite3`。

首次加载时，若新数据库不存在且发现旧插件的 `AstrBot/data/plugin_data/astrbot_plugin_pinjj/pinjj.sqlite3`，通过 SQLite 备份自动复制旧数据，保留旧文件。原 Rust bot 的 PostgreSQL 数据需要单独迁移。

签到按原消息去重，PK 和贷款在事务中结算，重复点击和并发请求复用已保存结果。v0.5.0 起新按钮使用 `dick:*` 回调标识；插件重载后本版按钮仍依赖 AstrBot 自身的持久化按钮数据。备份时停用插件并等待请求处理完成，备份游戏数据库及 AstrBot 数据目录。
